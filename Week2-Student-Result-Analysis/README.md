# Student Result Analysis

Analysis of student marks using NumPy, Pandas, and Matplotlib.

## Setup

```bash
cd Week2-Student-Result-Analysis
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python student_result_analysis.py
```

## Output

- Charts in `charts/` folder (3 PNG files)
- Cleaned data: `result_analysis_output.csv`

## Dataset

`student_marks.csv` - 30 students, 5 subjects (Math, Science, English, History, Geography)

Includes missing values, duplicates, and invalid data for cleaning demonstration.
