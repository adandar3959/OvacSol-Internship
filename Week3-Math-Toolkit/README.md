# Mathematical Foundations Toolkit for AI

Python toolkit implementing math concepts from first principles using NumPy.

## Setup & Run

```bash
cd Week3-Math-Toolkit
python -m venv venv
venv\Scripts\activate
pip install numpy matplotlib
python main.py
```

## Modules

**vectors.py** - Vector addition, subtraction, dot product, magnitude  
**matrices.py** - Matrix operations, transpose, determinant, inverse, linear solver  
**calculus.py** - Numerical derivatives, gradient descent  
**probability.py** - Coin flips and dice roll simulations  
**statistics.py** - Mean, median, mode, variance, standard deviation  
**main.py** - Demonstrates all modules + Linear Regression from scratch

## Output

- `charts/regression_plot.png` - Linear regression visualization
- `charts/probability_distribution.png` - Dice probability comparison
